# Clinic Management System

A PHP-based clinic management web application developed using **PHP, MySQL, and Twig**. The application provides separate panels and functionality for patients, doctors, and administrators, allowing users to manage appointments and clinic-related activities.

## Features

* Home page where patients can book an appointment
* Patient registration and login
* Doctor registration and login
* Separate panels for patients, doctors, and administrators
* Patient dashboard
* Doctor dashboard
* Administrator dashboard
* Appointment scheduling
* Appointment management
* Patient and doctor management
* User profiles
* Medical records
* Prescriptions and treatments
* Patient-doctor communication through chat
* Password management
* User account management

## Technologies

* **PHP**
* **MySQL**
* **Twig**

## Description

The application provides a simple and organized way to manage a clinic. Patients can book appointments directly from the home page, while doctors and administrators have their own panels for managing their respective tasks and information.
